# selecont presentations

The repository contains two finished presentation packages.

## 3-minute pitch

[`pitch-3min/`](pitch-3min/) is the compact 13-frame animated pitch prepared for a three-minute presentation. One extra click on the last frame switches from the Plus revenue hypothesis to the founder and the next-step request.

- [Run and controls](pitch-3min/README.md)
- [Russian speaker notes](pitch-3min/SPEAKER-NOTES.md)
- [English speaker notes](pitch-3min/SPEAKER-NOTES-EN.md)
- [Russian PDF](../output/pdf/selecont-pitch-3min-ru.pdf)
- [English PDF](../output/pdf/selecont-pitch-3min-en.pdf)

The language can be switched inside the interactive presentation without restarting it. All visual assets are stored locally, so the deck works offline after the repository has been cloned.

## Full application deck

[`presentation/`](presentation/) contains the longer bilingual application deck, its animated browser version and the original PDF exports used for the ITMO Accelerator application.

Both packages preserve the approved selecont wordmark, blue ring system and the product distinction between profile context, post audience and discussion context.
