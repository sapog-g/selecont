# selecont · pitch deck для заявки ИТМО

Финальная версия от 25.09.2026: 17 сцен на русском и английском в браузерной презентации и два PDF 16:9 для чтения без анимации.

- [Русский PDF](exports/selecont-itmo-2026-ru-v3.pdf) — основной файл для заявки.
- [English PDF](exports/selecont-itmo-2026-en-v3.pdf) — смысловая пара.

Для просмотра движения локально из корня репозитория: `python3 -m http.server 8043 --bind 127.0.0.1 --directory deck/presentation`, затем открыть `http://127.0.0.1:8043/`. Стрелки или клик по кадру переключают сцены, кнопка EN — язык, «Темп» — скорость. Слайды с кольцами, четырьмя секторами общего диска и AI Privacy Check сохраняют композицию утверждённого T08.2A. Остальные сцены расширяют рассказ, не меняя продукт и roadmap.

Кадр о готовности содержит три снимка настоящего локального демо с тестовыми данными. Проблема теперь идёт сразу после обложки; общий пост показан в пересечении трёх кругов Эйлера. 95 автоматических проверок прошли 25.09.2026. На кадрах AI и Context Suggestions указано, что это будущие функции. PDF построены из браузерных кадров 1600×900; они статичны и не заменяют анимационную версию.

Контакт на последнем кадре отсутствует по решению автора. PDF остаются статичными файлами для чтения и отправки. Исходники интерактивной версии готовы для GitHub Pages, когда владелец решит открыть её публично.
