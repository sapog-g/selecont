# selecont — анимационный питч на 3 минуты · RU / EN

Короткая двуязычная версия для трёхминутного выступления: 13 кадров и два последовательных состояния финала. Исходная полная презентация в `../presentation/` сохранена.

## Запуск

Из папки проекта:

```sh
python3 -m http.server 8044 --bind 127.0.0.1 --directory deck/pitch-3min
```

Открыть http://127.0.0.1:8044/ в Chrome. Интернет для самой презентации не нужен: шрифты, фотографии и графика локальные. Английскую версию можно открыть сразу по адресу http://127.0.0.1:8044/?lang=en.

## Управление

- **→ / пробел / щелчок по слайду** — дальше.
- **←** — назад.
- **F** — полный экран; **Esc** — выйти.
- **Home** — обложка; **End** — финал с основателем.
- **RU / EN** — переключить язык без перезапуска презентации.
- На **13-м** кадре сначала Plus, следующее нажатие показывает основателя и запрос. Номер остаётся 13 / 13.

[Утверждённая русская речь](SPEAKER-NOTES.md) и [английская версия](SPEAKER-NOTES-EN.md) синхронизированы с кадрами. Русский текст нужно репетировать вместе с переключением слайдов; предыдущий замер пользователя 2:48 относится к чтению без полного прогона переходов.

## Содержание и проверка

Сохранены оригинальные кольца и геометрия диска. Три круга Эйлера показывают аудитории одной публикации; комментарии иллюстрируют отдельные обсуждения. Новые фотографии Гриши — сгенерированные иллюстрации истории, а три экрана прототипа — реальные локальные интерфейсы с тестовыми аккаунтами. Обе подсказки отмечены как будущие функции; Plus — гипотеза, состав подписки ещё не определён.

PDF-версии для отправки находятся в [`../../output/pdf/`](../../output/pdf/). В них сохранены все 13 кадров и отдельная страница с финальным состоянием основателя.
